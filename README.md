# 📝 3rd Years CDC Assessments Data

Welcome to the **3rd Years CDC Assessments Data** repository! This project is geared toward organizing, tracking, and visualizing Career Development Center (CDC) assessment data for 3rd-year students.

## 📊 Live Dashboard
**[View the Power BI Dashboard Here](https://app.powerbi.com/view?r=eyJrIjoiODkwNzVhN2EtNGM1Mi00YWU3LThmY2UtMDNlNWU0NGNjYWM0IiwidCI6IjM3MjIxNDEwLWQzMzUtNDQ0OS05YjcwLWJmZTk3ZmM4Yzc4MiJ9)**

## 📁 Repository Contents
- **`Power BI DASHBOARD.png`**: Interface preview of the assessment dashboard.
- **`NRCM_CDC_Assessment_Dashboard_Report.pdf`**: Comprehensive structural report detailing the CDC assessment outcomes.
- **`3RD_YRS.xlsx`**: Excel file hosting the raw assessment scores, metrics, and mapped records.
- **`README.md`**: Project documentation.

## 🎯 Key Highlights
- **Skill Tracking**: Monitors and assesses student competencies pertinent to career placement and training.
- **Batch Comparisons**: Compare aggregate performances across different branches and batches.
- **Data Completeness**: Easy-to-read reports generated from comprehensive Excel sheets for management reviews.

## 🛠️ Tools Used
- **Power BI**: Data visualization.
- **MS Excel**: Primary data storage, transformation, and structural modeling.
