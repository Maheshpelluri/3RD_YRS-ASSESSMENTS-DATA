# 🎯 3rd Years CDC Assessments Data: Mapping Skills to Careers
*A specialized analytics project tracking Career Development Center (CDC) assessments to visualize student aptitude, soft skills, and placement readiness.*

## 📖 The "Why" behind this Project
Academic marks only tell half the story. The truth about a student's employability lies in their CDC (Career Development Center) Assessment scores—covering logical reasoning, coding logic, and verbal ability. 
This project parses through thousands of specialized aptitude test records, normalizing the data to create a high-impact dashboard tailored for Placement Officers and University Directors. It demonstrates my ability to pivot from traditional academic data into Human Resources/Recruitment-focused analytics.

---

## 🔍 Deep Dive: What's Inside?

### 🧩 1. The Core Assessment Data (`3RD_YRS.xlsx`)
This file is the engine of the project.
- **Skill Mapping:** Categorizing individual test questions into broader skill buckets (e.g., Quantitative Aptitude vs. Technical Coding).
- **Metric Formulation:** Creating weighted averages that prioritize core technical skills over general knowledge for tech-specific placement tracking.

### 📊 2. The Power BI Skill Dashboard (`Power BI DASHBOARD.png`)
**[👉 Experience the Live Interactive Dashboard Here](https://app.powerbi.com/view?r=eyJrIjoiODkwNzVhN2EtNGM1Mi00YWU3LThmY2UtMDNlNWU0NGNjYWM0IiwidCI6IjM3MjIxNDEwLWQzMzUtNDQ0OS05YjcwLWJmZTk3ZmM4Yzc4MiJ9)**
- **Competency Radars:** Visual representation of a batch's strengths vs. weaknesses across multiple aptitude categories.
- **Employability Scoring:** An aggregated "Readiness Score" allowing recruiters to instantly filter for the top candidates suited for high-tier tech interviews.
- **Branch-wise Comparison:** Pitting different engineering branches against each other to foster competitive academic growth.

### 📑 3. The Assessment Report (`NRCM_CDC_Assessment_Dashboard_Report.pdf`)
A heavily stylized PDF report detailing the CDC assessment outcomes. It features qualitative insights derived from the quantitative data, giving leadership actionable advice on where students are failing most frequently in mock interviews.

## 💡 Business Impact & Value
- **Higher Placement Ratios:** By identifying specifically *where* students are failing aptitude tests, trainers can focus on high-impact tutoring.
- **Corporate ROI:** Demonstrates to potential corporate recruiters that the institution deeply tracks and nurtures top talent.

## 🛠️ Technical Arsenal
- **Data Structuring:** Advanced Excel formatting, nested IFs, and lookup arrays for skill bucketing.
- **Data Storytelling:** Translating dry test scores into a narrative about career readiness using Power BI.
